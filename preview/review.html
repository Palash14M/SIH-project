📋 Executive & Architectural Summary for Reviewers

This system is a full-stack, production-grade inspection governance ecosystem built for the Ministry of Social Justice and Empowerment (MoSJE) under Smart India Hackathon problem statement SIH26095. It eliminates delayed reporting, ghost inspections, and milestone fraud across public works (hostels, residential schools, welfare facilities, flyovers, roads, and water supply).

📱 Android Native (Java 17 / SDK 34)
  • CameraX in-app capture ONLY (zero gallery picker permissions)
  • Hardware GPS lock: Strictly blocks evidence if accuracy > 100m
  • Pixel-level burned watermark: for the people to the people (40% opacity)
  • Room Database offline queue + WorkManager sync
⚡ High-Performance REST API (PHP 8.3)
  • 37 SQLite relational tables with cascading foreign keys
  • 100% prepared PDO statements (SQLi immune)
  • HMAC-SHA256 stateless JWT authentication
  • Automated PDF report generator & CSV bulk importer

🔄 8-Step Inspection State Machine & Critical Rules

Every inspection strictly transitions through the deterministic state machine. Skipping states or premature closures are strictly blocked at the database and middleware layers.

8. CLOSED
Mandatory Re-Inspection Gate (Zero Premature Closure) An inspection that enters ISSUE_RAISED cannot ever be closed directly. The system enforces that a re-inspection must be scheduled (REINSPECTION_PENDING) and a subsequent inspection must record a PASSED outcome before the tender inspection can achieve CLOSED status.
Anti-Fraud Escalation Fee Engine (₹400 + 18% GST = ₹472) When an approved NGO escalates a grievance up the hierarchy (Senior Officer ➔ District Officer ➔ State Officer ➔ MoSJE Admin), they must submit a statutory anti-spam deposit of ₹472.00. If the higher authority decides the grievance is UPHELD, the fee is 100% automatically refunded to the source payment method. If REJECTED, the deposit is permanently forfeited.
Citizen Nudge 1-per-Day & Chance-Burning Rule Citizens can nudge an attached NGO regarding lagging public works. Each citizen is restricted to strictly 1 nudge per calendar day across the entire system. Submitting an empty reason or a reason under 10 characters immediately burns the day's chance and delivers nothing to the NGO.
Server-Enforced Data Privacy & Contractor Masking Contractor and inspector personal phone numbers, emails, and residential addresses are permanently masked for public and unauthenticated users across all API responses.
